# ⚡ QR Forge

### 🎨 Create it. 📲 Scan it. 🚀 Share it.

A simple, modern, and customizable QR Code Generator.

[🇬🇧 English](#english) • [🇮🇷 فارسی](#فارسی)

---

## 🌐 English

QR Forge is a lightweight QR Code Generator that runs directly in your browser. Create QR codes from text and URLs, customize their appearance, and download them as PNG images.

### ✨ Features

- 🔗 Generate QR codes from text and URLs
- 🎨 Customize QR code and background colors
- 📐 Multiple output sizes
- 🛠️ Adjustable error correction levels
- 📥 Download QR codes as PNG images
- 📋 Copy text to the clipboard
- 🌙 Modern dark interface
- 📱 Responsive design
- ⚡ No backend server required

### 🌍 GitHub Pages

🚀 **Try QR Forge online:** [Open QR Forge](https://amiralidlb93-hash.github.io/qr-forge/)

### 🚀 Run Locally

1. Download or clone the repository.
2. Open `index.html` in your browser.
3. Start creating your QR codes!

> 💡 An internet connection is required to load the QR code library from the CDN.

## 🇮🇷 فارسی

QR Forge یک ابزار ساده، مدرن و کاربردی برای ساخت QR Code است که مستقیماً در مرورگر اجرا می‌شود. کدهای QR را از متن و لینک بسازید، ظاهر آن‌ها را شخصی‌سازی کنید و به‌صورت تصویر PNG دانلود کنید.

### ✨ امکانات

- 🔗 ساخت QR Code از متن و لینک
- 🎨 شخصی‌سازی رنگ کد و پس‌زمینه
- 📐 پشتیبانی از اندازه‌های مختلف
- 🛠️ تنظیم سطح تصحیح خطا
- 📥 دانلود QR Code با فرمت PNG
- 📋 کپی متن در کلیپ‌بورد
- 🌙 رابط کاربری مدرن با تم تاریک
- 📱 سازگار با اندازه‌های مختلف صفحه
- ⚡ بدون نیاز به سرور اختصاصی
